## 📖 About The Project

**Grid Portfolio** is a Persian RTL portfolio website that demonstrates real-world CSS Grid mastery. Every layout — from the hero section to the project cards — is built using CSS Grid with no layout frameworks. The site supports Persian numbers via custom font, includes video background, and is fully optimized for all screen sizes.



## ✨ Features

 Feature                      Description                                                     

 - **CSS Grid Layouts**     — All sections built with flexible CSS Grid — no Bootstrap layout 
 - **Fully Responsive**     — Works on mobile, tablet, and desktop                            
 - **Persian Font Support** — Vazir font with Persian numeral rendering                       
 - **RTL Direction**        — Full right-to-left Persian language support                     
 - **Responsive Navbar**    — Hamburger menu with sidebar for mobile                          
 - **Video Background**     — Contact me section with `.mp4` video                            
 - **WebP Images**          — Optimized images in modern WebP format                          
 - **Vanilla JavaScript**   — No jQuery — pure JS for interactions                            
 - **Bootstrap Icons**      — Icon set loaded locally (no CDN dependency)                     
 - **PWA Ready**            — Includes `site.webmanifest` for installability

## ⚙️ Getting Started


No build tools or dependencies needed. Just clone and open.

### 1. Clone the repository
---

```bash
git clone https://github.com/novixweb/grid-portofilo.git
```

### 2. Navigate to the project
---

```bash
cd grid-portofilo
```

### 3. Open in browser
---

Simply open `index.html` in your browser:

```bash
# Or use VS Code Live Server for best experience
```
